Access Control & Security Rules
Role-Based Access Control (RBAC): Strict backend verification via RoleAuthorizationInterceptor enforcing separated ADMIN and DONOR permissions.
Insecure Direct Object Reference (IDOR) Shield: Donors can only inspect batches and contribution reports belonging to their own verified identity.
Privilege Escalation Protection: Public registration strictly assigns DONOR role. Admin privileges cannot be assigned or manipulated from user forms.
